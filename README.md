# 冒险岛 · 石人寺院II（106010104）像素级复刻 Demo

在 macOS 上复刻「冒险岛怀旧服」金银岛·石人寺院II 的核心战斗玩法。画面素材来自
官方渲染图 + 原版 WZ 提取的怪物序列帧 + 录屏抠帧，刷怪配置与怪物数值取自官方数据，
平台碰撞（foothold）与藤蔓取自原版地图数据。

## 启动

```bash
./run.sh          # 自动找 conda env mxd 或系统 python3，缺 pygame 会自动装
# 或
python3 game/main.py
```

依赖：Python 3.9+，`pygame`（`pip install pygame`）。窗口 1280×724，60FPS。

## 操作

| 按键 | 动作 |
|---|---|
| ← → | 左右移动 |
| ↑ / ↓ | 攀爬藤蔓（绳底需跳跃中按↑抓绳，同原版） |
| 空格 | 跳跃 |
| ↓ | 趴下（脚下没有更低平台时） |

| F9 | **经验统计清零**（清空 kill_log.csv 与计数） |

| Esc | 退出 |

## 战斗机制（与原版录屏对齐 + 简化模式）

> 简化模式（按需求）：**MP 无限**（技能不耗魔）、**HP 自动快速回复**（120/秒，受击中也持续回复）、
> 不考虑死亡场景（HP 最低保留 1）。

- **挥拳（近身攻击）**：攻击键按下时若近身（水平 ≤55px / 垂直 ≤50px）有怪 → 挥拳：
  微量伤害（10）且**吸引仇恨**（怪物 3.5 秒追击），与 MP 无关；
  非近身 → 双飞斩。
- **触碰 MISS**：被怪物触碰时 **50% 概率 MISS**（`MXD_MISS_RATE` 可调）——
  不掉血、不击退、不硬直，头顶漂浮录屏同款 MISS 图案（约 0.7s 上浮消失），期间可自由行动；
  命中时才掉血并击退。每只怪触碰判定间隔 1 秒。
- **击退方向**（录屏逐帧取证确认的原版规则）：方向 = **远离怪物**；
  与怪物同 x 时退向背后（与朝向相反）。击退为短促位移（约 45px / 0.28s），
  硬直结束后无敌闪烁期内即可自由走/跳/攻击（bot 据此实现脱围）。
- **轻功（Haste, A 键）**：盗贼 2 转 Lv.20 数据——持续 **180 秒**；
  效果为游戏世界上限状态：满速 140%（140→196px/s）、满跳 120%（起跳速度 ×1.2，跳高 ≈104px）。
  右上角出现 buff 图标，剩余 <15 秒图标闪烁，到期消失；**闪烁中或消失时可再次释放**。

## 系统

- **刷怪**：全图恒定 15 只（官方配置：石头人×7 / 蓝蘑菇×4 / 猴子×3 / 蝴蝶精×1），
  按官方 15 个出生点位刷新；击杀后 **7 秒**在同一点位重生，**种类随机**（4 种中等概率）。
- **战斗**：每发飞镖固定伤害 1000 —— 石头人(HP 4000)恰好 2 次双飞斩打死，
  其余怪 1 次双飞斩内打死（简化规则）。怪物受击未死会仇恨追击、有击退与硬直；
  玩家被触碰 50% MISS（不掉血/不击退/可自由行动），命中时才有伤害数字与击退
  （方向=远离怪物），并有 2.2 秒无敌闪烁（闪烁期内即可自由走/跳/攻击）。
- **经验**：击杀按官方 EXP 结算（蓝蘑菇 32 / 蝴蝶精 120 / 猴子 77 / 石头人 170），
  右下角“得到经验值 (+N)”提示 + HUD EXP 条（满级需求 103400，由录屏 34981/33.83% 反推）。
- **统计与清零**：每次击杀追加写入 `logs/kill_log.csv`（time, mob_id, mob_name, exp），
  累计状态存 `logs/session_exp.json`；**F9 一键清零**。可直接用 pandas 读取分析。

## 三个系统

```
系统1  game/            游戏本体（本文件上半部分所述）
系统2  vision/          实时视觉监控（并行进程）
系统3  bot/             视觉驱动的自动战斗（模拟人手）
```

### 系统2：实时视觉监控

```bash
python3 game/main.py --ipc        # 终端1: 游戏(帧共享+虚拟键盘通道)
python3 vision/monitor.py         # 终端2: 监控(可加 --preview 生成标注帧)
```

- 帧来源：游戏的共享帧缓冲（等价于屏幕画面）；也支持 `--screen` 用 mss 抓真实屏幕。
- 识别：**名牌定位**（每个单位脚下的名字牌永不遮挡，全图NCC，怪物按类型匹配
  "Lv.55|石头人"等名牌模板）+ 角色武器红/深蓝/白帽颜色签名 + 名牌白条跟踪，
  三级回退。实测角色检出率 92%（平均误差 4px）、怪物精度 91.7%/召回 83%，~22fps。
- 输出 `/tmp/mxd_vision.json`：角色框、怪物列表、MP/HP 填充率(读HUD像素)、
  `can_skill`(能否放双飞斩)、`will_punch`/`punch_range`(近身≤62px→将挥拳)、
  `haste`{`present`/`blinking`/`can_recast`}(右上角轻功buff图标状态：消失或闪烁→可补放)、
  `hit`(受击)与操作建议。

### 系统3：模拟人手的自动战斗

```bash
python3 bot/autoplay.py --duration 90   # 终端3: bot(读视觉JSON → 写虚拟键盘)
```

- 只依赖系统2的识别结果与地图公开信息(平台/藤蔓)，不读游戏内部状态。
- 行为：选同层最近怪 → 接近 → 双飞斩（0.55-0.85s 人类化节奏）；每3-5次攻击插入
  **跳标**（起跳后空中丢镖）；跨层目标走藤蔓攀爬/下跳；**轻功管理**——视觉发现
  buff 图标消失/闪烁即按 A 补放（≥8s 人类化间隔）。
- **后撤丢镖（核心站位）**：贴太近会被迫挥拳（伤害≈0）且被反复触碰 → 保持 75~135px
  丢镖距离，<75px 边后撤边丢镖，<50px 后跳拉开；**永不主动挥拳**。
- **猴子是远程怪**：400px 内直接远距丢镖狙杀，无需接近（bot.log `[远距狙猴]`）。
- **被围殴脱离**（优先级最高）：≥2 只怪贴身（或贴身 + 连续受击）时，利用无敌时间——
  ① 朝怪物少的一侧**跳跃脱离**；② 下方更安全则**平台下跳**换层；
  ③ 上方更安全且藤蔓近（≤140px）则**爬藤向上**离层。bot.log 记录 `SURROUNDED` 决策。
- 60 秒实测：17 杀（四种怪全覆盖，含远狙猴子），日志在 `logs/bot.log`。
- 联调测试：`python3 tools/test_stack.py 90`（游戏+监控+bot 三进程并行）
- **录制完整操作视频**：`python3 tools/record_stack.py 90` → `videos/bot_gameplay.mp4`
  （从游戏帧共享内存抓画面，H.264 30fps，QuickTime 直接可开）

### 导航验证

```bash
python3 tools/test_nav.py    # 三个确定性场景
```

- 场景A(攀爬): 怪物全部移到上层，bot 在底层 → 走向藤蔓x=637、跳跃抓绳、攀爬到
  ~124 层并击杀（世界y轨迹 305→134，bot.log 记录“NAV 攀爬中/藤蔓顶端跳离”）。
- 场景B(下跳): 角色出生中层(300,121)、怪物在地面 → 按下+跳下跳/走下台阶
  （世界y轨迹 121→305，bot.log 记录“NAV 目标在下层, 下跳/走下台阶”）。
- 场景C(脱围): 3 只怪紧贴角色出生点（`MXD_MOBS_AROUND=1`）→ bot 记录 `SURROUNDED`
  并跳跃/换层脱离（位移 >100px 或 y 变化），同时完成轻功补放。
- 场景开关: `MXD_MOBS_UP=1` / `MXD_MOBS_GROUND=1` / `MXD_MOBS_AROUND=1` /
  `MXD_PLAYER_AT=x,y` (重生点随场景同步迁移；`MXD_TRUTH=1` 输出世界坐标真值供测试取证)。

### 与视频的已知差异

- 跳跃/趴下/爬藤为合成帧（录屏中未出现这些动作的完整画面）；行走/攻击/受击为录屏原帧。
- 伤害数字为字体渲染（描边样式对齐原版），MISS 为录屏抠图；怪物名牌为字体渲染。
- 底部聊天栏与跑马灯为静态切片；商城等按钮不可点（按需求仅保留核心战斗）。
- 相机边界较原版略收紧（左 -303），以保证天空无缝。
- 录屏为 18fps，动作动画帧率按原版节奏（60FPS 逻辑）重建。
